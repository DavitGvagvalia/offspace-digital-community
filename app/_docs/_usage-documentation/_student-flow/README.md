# Student Flow

Students create accounts at `/student/register` and sign in at
`/student/login`.

Students can:

- Open the student hub.
- Choose active courses when they do not already have enrollments.
- View enrolled courses.
- View assigned lessons.
- View personal attendance.
- View their read-only profile.

After course selection, group and mentor assignment can remain pending until a
mentor or super-admin assigns the student.
