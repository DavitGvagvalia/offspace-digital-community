## Starting Point

Open the app and use the home page links:

- Student login
- Mentor login
- Student registration
- Super-admin login

Use the portal that matches your account role. If you sign in through the wrong portal, the app will block access and sign you out.

## Account Access

Each account must have the correct portal profile:

- Students need a student profile.
- Mentors need a mentor profile.
- Super-admins need a super-admin profile.

If you can sign in but cannot access a portal, ask the Offspace team to confirm that your account has the correct profile and role.
