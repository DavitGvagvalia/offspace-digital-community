# Mentor Flow

## What Mentors Can Do

Mentors can:

- Sign in to the mentor portal.
- See groups assigned to their mentor account.
- Open a group workspace.
- View the course, lessons, students, and attendance records for an assigned group.
- Mark or unmark attendance for assigned students and group lessons.

Mentors cannot manage unrelated groups, create student accounts, or edit course enrollment setup from the current mentor dashboard.

## Sign In

1. Open the home page.
2. Select `Mentor login`.
3. Enter the mentor email and password.
4. Select `Continue`.

If the app says the account does not have access to the mentor portal, the signed-in Firebase account does not have a matching mentor profile.

## Dashboard

After login, the mentor dashboard loads groups assigned to the current mentor account.

If no groups appear, no assigned groups were found for that mentor account.

## Group Workspace

Select a group from the group list.

The workspace shows the selected group's schedule and attendance context. The data is loaded from:

- The assigned group.
- The group's course.
- The group's lessons.
- Enrollments for students assigned to the group and mentor.
- Attendance records for the group.

## Mark Attendance

Use the attendance controls in the selected group workspace.

When marking attendance:

- Selecting an empty attendance state creates an attendance record.
- Selecting an existing attendance state removes that attendance record.
- The app blocks changes if the group is not assigned to the current mentor account.
- The app blocks changes if the student or lesson does not belong to the selected group.

If an update fails, check the connection and confirm the student is actively enrolled in the group.
