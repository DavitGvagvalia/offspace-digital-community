# Mentor Flow

Mentors sign in at `/mentor/login`.

Mentors can:

- View upcoming lessons and ungrouped-student counts in the hub.
- View eligible courses and assign ungrouped students into their groups.
- Create and update groups for eligible courses.
- View assigned groups.
- Review group lessons and students.
- Mark or clear attendance for assigned group lessons.

Mentors cannot manage unrelated courses, unrelated groups, or create accounts.
