# App Documentation

This app is a Supabase-backed role-based schedule and attendance MVP.

- Auth: Supabase Auth email/password.
- Database: Supabase Postgres.
- Authorization: Postgres Row Level Security.

See `_code-documentation` for implementation notes and `_usage-documentation`
for role flows.

Start with `_code-documentation/project-structure.md` when you need to know
which file or directory owns a specific part of the app.
