# Project Overview

The project is a role-based schedule and attendance web app for Offspace Digital
Community.

Implemented portals:

- Student
- Mentor
- Super-admin

Current stack:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase Postgres
- Supabase Row Level Security

Firebase has been removed from active runtime and deploy configuration.
